# Grand Theft Snake

An original Python action game inspired by the top-down open-world games of the PS1 era. This fan-made project uses original names, characters, city, visuals, music, and sound effects. It does not include Rockstar Games code or game assets.

## Play

On this Mac, open **Grand Theft Snake.app** from the Applications folder. If Pygame CE is missing, the launcher offers to install it. The game requires Python 3.10 or later and Pygame CE.

## Controls

- **WASD / arrow keys**: walk; in a car, accelerate, reverse, and steer
- **E**: steal a nearby car or get out
- **F**: answer a payphone and accept a job
- **Space**: shoot, if you have ammunition
- **R**: change radio station while driving
- **Enter**: select or continue
- **Esc**: pause or go back
- **F11**: toggle fullscreen

## Features

The game opens with animated SN Colors Publisher and SN Colors Studio screens, followed by the main menu, character selection, and the city. It includes four playable characters, car theft, traffic, pedestrians, two phone jobs, weapons and ammunition, five wanted levels, police chases, arrest, bonus crates, bribes, a score multiplier, and a minimap. Music and sound effects are synthesized by the game.

The interface supports **Italian, English, French, and Spanish**. Choose a language in Settings; the selection is saved in `settings.json`.

## Project status

This is a prototype. The current macOS app launcher expects the project and Python installation to be present at their configured locations on this Mac. The app is not yet a self-contained release for other computers.
